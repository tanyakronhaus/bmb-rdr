# BMBY RADAR · תוכנית שיווקית להשקה

אתר מצגת (עמוד יחיד) של התוכנית השיווקית להשקת BMBY RADAR, בשפה העיצובית של bmby RADAR.

- `index.html` – האתר כולו (HTML/CSS/JS ללא תלויות, פונטים Heebo ו‑Montserrat מ‑Google Fonts).
- `assets/` – הלוגו ושלושת הרקעים.

ניווט: גלגלת, חיצים במקלדת, החיצים בסרגל העליון או הנקודות בסרגל ההתקדמות התחתון. בטלפון השקפים נערמים לגלילה רגילה.
פתיחה: לפתוח את `index.html` בדפדפן (או להגיש את התיקייה מכל שרת סטטי).
